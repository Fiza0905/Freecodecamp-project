# FreeCodeCamp Website

A responsive educational website inspired by the FreeCodeCamp website. This project was created as a frontend development practice project to improve my skills in HTML, CSS, Bootstrap, responsive design, and website layout.

## Features

* Responsive navigation header
* Search bar
* Language and menu dropdowns
* Hero section with call-to-action button
* Learning and education sections
* Alumni testimonials section
* Recommended curriculum section
* Course catalog cards
* Frequently Asked Questions section
* Responsive mobile layout
* Hover effects and interactive elements

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Font Awesome
* JavaScript

## Project Purpose

This project was created for learning and frontend development practice. FreeCodeCamp inspired the design and content, and I built and customized the website as my own coding practice.
