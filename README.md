# FreeCodeCamp Website

A responsive educational website inspired by the FreeCodeCamp website. This project was created as a frontend development practice project to improve my skills in HTML, CSS, Bootstrap, responsive design, and modern website layouts.

## Features

- Responsive navigation bar
- Search functionality design
- Language and menu options
- Hero section with call-to-action
- Educational and learning sections
- Alumni testimonials
- Recommended curriculum section
- Course catalog with cards
- Frequently Asked Questions (FAQ) section
- Responsive layout for mobile and desktop
- Hover effects and interactive UI elements

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- JavaScript

## Project Purpose

The main purpose of this project was to practice frontend web development and improve my ability to create responsive and user-friendly website layouts.

The project is inspired by the design and structure of FreeCodeCamp, but it was developed and customized as part of my own frontend development practice.

## Responsive Design

The website is designed to provide a consistent user experience across different screen sizes, including:

- Desktop
- Tablet
- Mobile
